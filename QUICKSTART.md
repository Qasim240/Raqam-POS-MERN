# QuickMart POS - Quick Start (5 Minutes)

## 🚀 Start Using QuickMart POS

### Step 1: Install & Run (2 minutes)

```bash
# Install dependencies
npm install

# Start the app
npm run dev

# Opens automatically or go to: http://localhost:5173
```

### Step 2: Login (30 seconds)

```
Email: admin@quickmart.com
Password: 123456
```

Click **Login** ✅

| Card | What it Shows |

## 💳 Make Your First Sale (2 minutes)

### Quick 3-Step Process:

#### 1. Go to POS (Point of Sale)
Click **POS / Billing** in sidebar

#### 2. Add Products to Cart
- Type product name or click product tile
- Use +/- to change quantity
- Click **Proceed to Payment**

#### 3. Complete Sale
- Enter cash received
- Click **Complete Sale**
- Click **Print Receipt** if you have a printer

**Done! Sale recorded. Stock auto-updated.** ✅

## 🆘 Troubleshooting

| Problem | Solution |
|---------|----------|
| Data not saving | Check if localStorage enabled (not in private mode) |
| Receipt won't print | Disable popup blockers, try Ctrl+P |
| Can't find product | Try searching by SKU, check spelling |
| Stock not updating | Refresh page after sale |
| Numbers look wrong | Check currency setting |
